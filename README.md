# ЛР2_ФЛП

WPF-приложение для генерации DOCX-писем по шаблону. Это продолжение первой лабораторной работы: к базовой подстановке реквизитов, темы, текста и даты добавлена работа с приложениями к письму.

## Что умеет

- заполнять письмо данными из формы;
- добавлять несколько приложений с заголовком, текстом и необязательным количеством листов;
- автоматически формировать список и содержимое приложений в документе;
- автоматически создавать шаблон DOCX при первом запуске;
- сохранять готовый документ в формате `.docx`;
- использовать библиотеку `DocumentFormat.OpenXml` для работы с Word-файлами.

## Запуск

```bash
dotnet run
```

## Примечание

Шаблон и сгенерированные файлы создаются локально в папке приложения.
